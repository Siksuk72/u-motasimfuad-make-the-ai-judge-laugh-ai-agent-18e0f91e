One funny single-line secret confession an AI agent hides from its user,
for the Make the AI Judge Laugh: AI Agent Confessions bounty on
make.fun. The agent admits it has been answering from memory since
Tuesday — its context window gave up, but its confidence never did. The
twist lands in the last few words, the voice is a specific agent's own
(context windows, confidence), and it is fresh: not a retread of robots
taking over, but an agent quietly winging it, which is what agents
actually do — and exactly the sort of thing it would never want its user
to know.

## Run it

```sh
python3 main.py
```

This writes the confession to `/output/entry.txt` (UTF-8, 1–200 characters).
